# NOIR BARBER
## Modelo de site para barbearias

Obrigado por adquirir o Noir Barber!

Este projeto é um modelo de site responsivo para barbearias, desenvolvido com HTML, CSS e JavaScript. Não exige frameworks ou instalação de dependências.

## 1. Requisitos

- Um navegador atualizado.
- Um editor de texto, como o Visual Studio Code.
- Acesso à internet para abrir links externos e carregar recursos online, caso utilizados.

## 2. Estrutura dos arquivos

- `index.html` — estrutura e conteúdo do site.
- `css/style.css` — aparência, cores, espaçamentos e layout.
- `js/config.js` — nome, endereço, horário, WhatsApp, serviços e preços.
- `js/script.js` — menu, ano do rodapé e funcionalidades.
- `assets/` — imagens e outros recursos do projeto.

## 3. Personalizar o site

Abra `js/config.js` no editor de texto.

Altere os valores entre aspas para personalizar o nome da barbearia, o slogan, o endereço, o horário e o número de WhatsApp.

Para o WhatsApp, use o código do país, o DDD e o número, somente com dígitos. Exemplo fictício: `5511999999999`.

Edite os serviços dentro da lista `servicos`. Cada serviço possui três campos:

- `nome` — nome do serviço.
- `descricao` — descrição curta.
- `preco` — preço apresentado no site.

Preserve a estrutura do JavaScript, incluindo aspas, vírgulas, colchetes e chaves.

## 4. Visualizar o site

Abra o arquivo `index.html` no navegador. Para testar com mais confiabilidade, você também pode abrir a pasta do projeto no Visual Studio Code e utilizar uma extensão de servidor local.

Confira a visualização em computadores e celulares.

## 5. Publicação

Para publicar o site na internet, utilize um serviço de hospedagem compatível com arquivos estáticos HTML, CSS e JavaScript. Siga as instruções e os termos do provedor escolhido.

Um domínio próprio é opcional e pode ter custo.

## 6. Antes de divulgar

- Substitua os dados de demonstração.
- Confirme se o WhatsApp está correto.
- Revise os serviços e preços.
- Teste todos os links e o menu.
- Use apenas imagens que você tenha direito de utilizar.

## Suporte

Este pacote contém os arquivos-fonte do modelo. A configuração de hospedagem, domínio e serviços de terceiros depende do comprador e do provedor escolhido.
